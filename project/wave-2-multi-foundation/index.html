    Wave 2 Multi-Repo Foundation¶

    Date: 2026-02-25

    Objective¶

    Deliver multi-repo registry and scoped cross-repo operations as the Wave 2 foundation.

    Completed¶

    1. New module crate: pilot-multi
    2. Introduced crates/pilot-multi with a SQLite-backed registry.

    3. Added workspace membership and CLI dependency wiring.

    4. Registry schema and operations

    5. Registry DB path: ~/.pilot/workspace.db
    6. Tables:
    7. repos (name/path/group)
    8. repo_tags (many-to-one tags)
    9. Implemented:
    10. register repo (upsert by canonical path)
    11. list repos

    12. status fanout over selected repos

    13. Scoped selection model

    14. Added RepoFilter with:
    15. group
    16. repeated tags
    17. Filter semantics:
    18. group exact match

    19. all provided tags must be present on repo

    20. CLI surface integrated

    21. Added pilot multi command group with:
    22. pilot multi register --path ... [--name ...] [--group ...] [--tag ...]
    23. pilot multi list [--group ...] [--tag ...]
    24. pilot multi status [--group ...] [--tag ...]

    25. pilot multi query --query "..." [--group ...] [--tag ...] [--per-repo-limit N]

    26. Cross-repo Oracle query fanout

    27. Implemented async fanout query over selected repos.
    28. Per-repo behavior:
    29. if .pilot/graph.db or .pilot/vectors.lance missing, returns per-repo error

    30. otherwise runs query via pilot-oracle::QueryEngine

    31. Reporting integration

    32. multi.* commands now emit standardized CommandReport summaries.

    33. --report-json continues to work for multi commands.

    34. Tests

    35. Added CLI integration tests:
    36. tests/multi_cli_test.rs
    37. Added unit coverage in pilot-multi for register/list/filter behavior.

    Validation¶

    Passed in this environment: - cargo fmt --all -- --check - ./scripts/wave0_safety_check.sh

    Blocked by environment networking: - cargo check -p pilot --locked - cargo test -p pilot --locked

    Reason: DNS/network to index.crates.io is unavailable in this environment.

    Notes¶

    Wave 2 focused on multi-repo registry and fanout foundations only. Advanced cross-repo automation (branch orchestration, dependency-order merge planning, linked PRs) is part of subsequent phases.
